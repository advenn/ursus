# Step 496 — as built

**Tests from recorded oracles, not hand values: the framework and its pilot.** Set by
the maintainer on 2026-11-05: "regarding tests, make it test dynamic values, not
handcrafted tests." [`oracle-v2-scope.md`](./oracle-v2-scope.md) is the scope; this is
its §2. A test's expected value was its author's belief, typed; it is Polars 2.1.0's
answer now, produced by a script, checked in as data, and regenerated by CI.

## 1. What

- **`bench/scripts/oracle/`**, a Python package: `__init__.py` (the `Case`, the
  groups), `encode.py` (a Polars frame to the format, every type ursus has), `gen.py`
  (seeded generators a type, with a null rate and the type's edges), `__main__.py`
  (`python -m bench.scripts.oracle [group ...]` from the repository root; `make
  oracle` runs it, `ORACLE_PYTHON` naming the interpreter), `requirements.txt`
  (polars 2.1.0, numpy 2.5.4), and a module a group: `expressions.py` (step 184's 46
  cases, moved from `oracle_expressions.py`, which is a two-line stub now, with
  Describe and ValueCounts as frames), `format.py`, `numodds.py`, `rollmore.py`,
  `dtmore.py`. The runner refuses a Polars other than 2.1.0 and writes
  `testdata/oracle/<group>.json` deterministically: keys sorted, indent 1, a newline.
- **`oracle_test.go`**, in the root package: the loader (a recorded frame to a
  `*ursus.LazyFrame` through `Values`, `ValuesNullable` and `Cast`, a List by imploding
  its flattened elements over their row, a Struct by `Struct` of its fields, an Array
  through `List().ToArray`), a parser of the types as ursus prints them, the registry
  `oracleGroups[group][name]`, `oracleDifferences`, and `TestOracle`, which runs every
  case of every group as `group/name`, asks ursus, builds the recorded answer the
  same way and compares with `ursustest.AssertFrameEqual`: dtypes checked, floats by
  bits (its default rendering, 'g' at full precision, tells −0 from 0 and NaN equals
  NaN), `order: set` by `IgnoreRowOrder`, `float: rel:<x>` by `WithTolerance`, both
  by sorting on every column first. A refusal is asserted as an error naming the
  recorded phrase. The registry and the recordings are checked against each other
  both ways. Each group registers in its own `oracle_<group>_test.go`; nothing new is
  exported.
- **`.github/workflows/oracle.yml`**: on a pull request touching the recordings, the
  generators or itself, and by hand, Python 3.12 installs the requirements, records
  every group and `git diff --exit-code -- testdata/oracle`. Not a required check
  until it has run green on three pull requests.
- **The pilot:** `numodds_test.go`, `rollmore_test.go` and `dtmore_test.go` converted.

261 cases in five groups: expressions 48, format 11, numodds 81, rollmore 66, dtmore
55; 27 generated, 4 refusals.

## 2. The format, by one case

`testdata/oracle/numodds.json`, the case `round_even_0`, as recorded:

```json
{"float": "bits", "name": "round_even_0", "order": "rows",
 "inputs": {"df": {"columns": [{"dtype": "Float64", "name": "x",
   "values": [0.5, 1.5, 2.5, -0.5, -2.5, 2.675, 0.125, 1e+300, "NaN", null, -0.4]}]}},
 "want": {"columns": [{"dtype": "Float64", "name": "x",
   "values": [0.0, 2.0, 2.0, "-0.0", -2.0, 3.0, 0.0, 1e+300, "NaN", null, "-0.0"]}]}}
```

Python asked `df.select(pl.col("x").round(0, mode="half_to_even"))`;
`oracle_numodds_test.go` spells it `in.df().Select(x.Round(0, ursus.RoundHalfToEven))`.
A type is spelled as `dtype.DataType.String()` does: `Uint8` (not Polars' `UInt8`),
`Datetime(us, Europe/Paris)`, `Time(ns)`, `Duration(ms)`, `Decimal(12, 4)`, `Enum(a,
b)`, `List(Int64)`, `Array(Float64, 3)`, `Struct(a: Int64, b: String)`. A value is JSON:
an integer a number, an Int128 or a Decimal's unscaled integer a string, a float a
number or `"NaN"`, `"inf"`, `"-inf"`, `"-0.0"`, a Date its days, a Datetime, Duration or
Time its ticks, Binary base64, a Categorical or Enum its text, a List a list, a Struct
an object. A refusal is `"want": {"error": {"polars": "InvalidOperationError: ...",
"contains": "not defined"}}`. `params` and `note` are written when set. The `format`
group puts every type through the identity, generated, so the encoder and the loader
are proved to agree on each, nested ones included.

## 3. How to add a group

1. `bench/scripts/oracle/<group>.py` with `def cases() -> list[Case]`, each
   `case(name, frame_or_inputs, lambda df: <the Polars query>, order=, float=, note=,
   contains=)`; add the name to `GROUPS` in `__init__.py`. Generated inputs come from
   `Gen(seed)`; a tolerance says why in `note`.
2. `make oracle GROUPS=<group>` (or `python -m bench.scripts.oracle <group>`).
3. `oracle_<group>_test.go`: `func init() { oracleGroups["<group>"] =
   map[string]oracleQuery{"<name>": func(in oracleInputs) *ursus.LazyFrame {...}} }`.
   `in.df()` is the input named `df`, `in.frame("left")` another, `in.eager(df, err)`
   an eager answer.
4. `go test -run 'TestOracle/<group>' .`. A case ursus answers otherwise on purpose
   goes in `oracleDifferences` as `"<group>/<name>"` with its reason and the cells or
   dtypes ursus gives; a difference not meant is fixed.

## 4. The pilot

| file | lines before | after | hand-typed values before | after | cases | generated |
| --- | --- | --- | --- | --- | --- | --- |
| `numodds_test.go` | 399 | 70 | 118 lines | 0 | 81 | 6 |
| `rollmore_test.go` | 409 | 160 | 97 | 0 | 66 | 3 |
| `dtmore_test.go` | 478 | 208 | 90 | 0 | 55 | 8 |

What stays in the three files asserts structure: the refusals and their phrases, a
plan's text, and what Polars 2 has no answer for, held to Go's own oracles:
`with_time_unit` (gone from Polars 2; the ticks are the operand's, a differential),
Dublin's and Casablanca's zone offsets (the zone database's form, main or rearguard,
differs between Debian and Ubuntu's CI; their sum is Go's offset and the saving is
non-zero where Go's `IsDST` is), a gap made null by `NonExistentNull` (`dt.replace`
lost `non_existent`; Go's `time.Date` says whether the clock exists), and
`RollingCorr`'s invariance of `Ddof` (Polars 2.1's `rolling_corr` lost the argument).
The four shared cell readers moved to `cells_test.go`. Dropped as covered by the
recordings' dtypes and names: the type checks (`Duration(ms)`, `Int32` days, a clipped
`Int32`) and `rolling_cov`'s name. `cot(pi/2)`, held by its absolute error, is the
case `cot_pole` at rel:1e-14, with the reason.

## 5. What the oracle found

Polars 1.44.1's pasted values against 2.1.0's answers, and ursus against both:

- **`ewm_std_halflife2` and `ewm_var_span4_noadjust`** moved by an ulp between 1.44.1
  and 2.1.0 (step 487 compared them to 1e-12 and called them identical). ursus answers
  1.44.1's bits. Held to rel:1e-12 with the reason, as are `rolling_var_3_min2`,
  `rolling_std_4_min1_ddof0`, `ewm_mean_alpha05`, `ewm_var_alpha03_bias` and
  `describe`'s std, where ursus is an ulp or two from Polars and the old test's 1e-9
  hid it: a variance's merge order, feature-gaps.md §1.
- **`Clip`, `ClipLower` and `ClipUpper` named their answer after the bound,** "literal"
  for a Go number and "lo" for `Col("lo")`, where Polars keeps the value's name. Every
  test aliased the answer. Fixed in `fill.go`: the value is each conditional's Then and
  the bound its Otherwise; a null comparison keeps the value as before. In the
  CHANGELOG's Fixed.
- **`dt.hour` is an Int32** here, as every component is (expr_dt.go), and Polars' an
  Int8: `expressions/convert_tokyo_hour` in `oracleDifferences`, its dtype.
- **A count is a Uint64** here, so that it cannot wrap at 2^32 rows where Sum was
  widened not to (`internal/expr.ResolveAggBinding`), and Polars' a UInt32: a frame's
  `ValueCounts` counts with `Len`; `expressions/value_counts` in `oracleDifferences`.
- **A centred rank whose window ends in a null:** Polars null, ursus the rank (step
  284's own note): `rollmore/rank_min_3_center_null_after` in `oracleDifferences`.
- **`rolling_sum_by_1d`'s all-null window:** Polars 0.0, ursus null, as since step 184.
- Every other pasted value of the three files is Polars 2.1.0's answer too, the
  Date's `replace(hour=4, day=2)` included, which Polars answers as ursus does.

## 6. Teeth

| mutation | |
| --- | --- |
| `round_even_0`'s recorded 2.0 at row 1 made 2.0000000000000004 | **bites:** `row 1 differs: got 2, want 2.0000000000000004` |
| the loader reading `"-0.0"` as 0 | **bites:** `truncate_0`: `row 1 differs: got -0, want 0` |

Both undone: the loader edited back, the recording regenerated (deterministic: the
file is byte-identical).

## 7. Checks

`go test .` in full, `go test ./internal/gen/...`, `go vet ./...`, `make api` (0
gone), all under `GOEXPERIMENT=simd GOAMD64=v3`. The oracle recorded three times to
the same bytes (`md5sum -c`): the first attempt was not, because a group-by's rows
came in Polars' hash order, another each run, so an `order: set` answer is sorted on
every column as it is recorded; the test compares it as a set either way.

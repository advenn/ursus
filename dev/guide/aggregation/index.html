    Aggregation and group-by¶

    GroupBy(keys...) splits the rows by their keys, and Agg(exprs...) computes each expression once per group: one row per group comes out, its keys and its aggregates.

    The aggregates¶

    df, err := sales().
    GroupBy(ursus.Col("region")).
    Agg(
        ursus.Col("qty").Sum().Alias("sum"),
        ursus.Col("qty").Mean().Alias("mean"),
        ursus.Col("qty").Median().Alias("median"),
        ursus.Col("qty").Min().Alias("min"),
        ursus.Col("qty").Max().Alias("max"),
        ursus.Col("qty").Std(1).Round(2).Alias("std"),
    ).
    Sort(ursus.Asc(ursus.Col("region"))).
    Collect(context.Background())
if err != nil {
    log.Fatal(err)
}
fmt.Println(df)
    Output
    shape: (3, 7)
┌─────────┬────────┬───────────────────┬─────────┬───────┬───────┬─────────┐
│ region  │ sum    │ mean              │ median  │ min   │ max   │ std     │
│ String  │ Int128 │ Float64           │ Float64 │ Int64 │ Int64 │ Float64 │
├─────────┼────────┼───────────────────┼─────────┼───────┼───────┼─────────┤
│ "east"  │ 14     │ 7                 │ 7       │ 2     │ 12    │ 7.07    │
│ "north" │ 20     │ 6.666666666666667 │ 7       │ 3     │ 10    │ 3.51    │
│ "south" │ 19     │ 6.333333333333333 │ 6       │ 4     │ 9     │ 2.52    │
└─────────┴────────┴───────────────────┴─────────┴───────┴───────┴─────────┘

    The usual statistics are all there:

    • Sum, Mean, Median, Min and Max;
    • Std(ddof) and Var(ddof);
    • Quantile(q, interpolation);
    • Product;
    • Skew, Kurtosis and Entropy;
    • Corr, Cov and CorrSpearman of two columns.

    Every aggregate skips nulls. A mean is over the values that are there, and a group with no values sums to null, not 0. An integer sum is an Int128, so it cannot overflow: cast it to Int64 if you want Polars' type.

    Counting has several forms, each one value per group:

    df, err := sales().
    GroupBy(ursus.Col("product")).
    Agg(
        ursus.Len().Alias("orders"),
        ursus.Col("region").NUnique().Alias("regions"),
        ursus.Col("region").First().Alias("first"),
        ursus.Col("region").Last().Alias("last"),
    ).
    Sort(ursus.Asc(ursus.Col("product"))).
    Collect(context.Background())
if err != nil {
    log.Fatal(err)
}
fmt.Println(df)
    Output
    shape: (3, 5)
┌─────────┬────────┬─────────┬─────────┬─────────┐
│ product │ orders │ regions │ first   │ last    │
│ String  │ Uint64 │ Uint64  │ String  │ String  │
├─────────┼────────┼─────────┼─────────┼─────────┤
│ "apple" │ 3      │ 3       │ "north" │ "east"  │
│ "fig"   │ 2      │ 2       │ "south" │ "north" │
│ "pear"  │ 3      │ 3       │ "north" │ "south" │
└─────────┴────────┴─────────┴─────────┴─────────┘
    • Len() counts a group's rows;
    • Count() counts a column's values that are not null;
    • NUnique() counts its distinct values, a null not among them;
    • First() and Last() are its first and last value in the rows' order.

    Keys¶

    A key is any expression, not only a column. Alias a computed key to name it:

    df, err := sales().
    GroupBy(ursus.Col("qty").Ge(8).Alias("bulk")).
    Agg(ursus.Len().Alias("orders"), ursus.Col("qty").Sum().Alias("qty")).
    Sort(ursus.Asc(ursus.Col("bulk"))).
    Collect(context.Background())
if err != nil {
    log.Fatal(err)
}
fmt.Println(df)
    Output
    shape: (2, 3)
┌───────┬────────┬────────┐
│ bulk  │ orders │ qty    │
│ Bool  │ Uint64 │ Int128 │
├───────┼────────┼────────┤
│ false │ 5      │ 22     │
│ true  │ 3      │ 31     │
└───────┴────────┴────────┘

    Several keys group by their combinations:

    df, err := sales().
    GroupBy(ursus.Col("region"), ursus.Col("product")).
    Agg(ursus.Col("qty").Sum().Alias("qty")).
    Sort(ursus.Asc(ursus.Col("region")), ursus.Asc(ursus.Col("product"))).
    Collect(context.Background())
if err != nil {
    log.Fatal(err)
}
fmt.Println(df)
    Output
    shape: (8, 3)
┌─────────┬─────────┬────────┐
│ region  │ product │ qty    │
│ String  │ String  │ Int128 │
├─────────┼─────────┼────────┤
│ "east"  │ "apple" │ 12     │
│ "east"  │ "pear"  │ 2      │
│ "north" │ "apple" │ 10     │
│ "north" │ "fig"   │ 3      │
│ "north" │ "pear"  │ 7      │
│ "south" │ "apple" │ 4      │
│ "south" │ "fig"   │ 9      │
│ "south" │ "pear"  │ 6      │
└─────────┴─────────┴────────┘

    Groups come out in no promised order: they are built on every core at once. Sort the answer, as these examples do, or ask for the order the keys first appear in with MaintainOrder():

    df, err := sales().
    GroupBy(ursus.Col("product")).
    MaintainOrder().
    Agg(ursus.Col("qty").Sum().Alias("qty")).
    Collect(context.Background())
if err != nil {
    log.Fatal(err)
}
fmt.Println(df)
    Output
    shape: (3, 2)
┌─────────┬────────┐
│ product │ qty    │
│ String  │ Int128 │
├─────────┼────────┤
│ "apple" │ 26     │
│ "pear"  │ 15     │
│ "fig"   │ 12     │
└─────────┴────────┘

    A null key is a group of its own, as in SQL's GROUP BY and Polars.

    Conditional aggregates¶

    An aggregate's input is an expression, so it can be narrowed or computed first:

    df, err := sales().
    GroupBy(ursus.Col("region")).
    Agg(
        ursus.Col("qty").Filter(ursus.Col("product").Eq("apple")).Sum().
            Alias("apple_qty"),
        ursus.Col("qty").Ge(8).Sum().Alias("bulk_orders"),
        ursus.Col("product").MaxBy(ursus.Col("qty")).Alias("biggest"),
    ).
    Sort(ursus.Asc(ursus.Col("region"))).
    Collect(context.Background())
if err != nil {
    log.Fatal(err)
}
fmt.Println(df)
    Output
    shape: (3, 4)
┌─────────┬───────────┬─────────────┬─────────┐
│ region  │ apple_qty │ bulk_orders │ biggest │
│ String  │ Int128    │ Int128      │ String  │
├─────────┼───────────┼─────────────┼─────────┤
│ "east"  │ 12        │ 1           │ "apple" │
│ "north" │ 10        │ 1           │ "apple" │
│ "south" │ 4         │ 1           │ "fig"   │
└─────────┴───────────┴─────────────┴─────────┘
    • Filter(pred) before an aggregate keeps a group's rows where pred is true: apple_qty sums only the apples;
    • a Bool sums as 0 and 1, so the sum of a condition counts the rows that meet it;
    • MaxBy(other) and MinBy(other) take a column's value where another column is largest or smallest: each region's biggest order's product.

    Lists per group¶

    Implode gathers a group's values into a list. Unique, Sort, Head and the other expressions that give several values give a list per group too:

    df, err := sales().
    GroupBy(ursus.Col("region")).
    Agg(
        ursus.Col("order_id").Implode().Alias("orders"),
        ursus.Col("product").Unique().Sort().Alias("products"),
    ).
    Sort(ursus.Asc(ursus.Col("region"))).
    Collect(context.Background())
if err != nil {
    log.Fatal(err)
}
fmt.Println(df)
    Output
    shape: (3, 3)
┌─────────┬─────────────┬──────────────────────────┐
│ region  │ orders      │ products                 │
│ String  │ List(Int64) │ List(String)             │
├─────────┼─────────────┼──────────────────────────┤
│ "east"  │ [4, 6]      │ ["apple", "pear"]        │
│ "north" │ [1, 3, 7]   │ ["apple", "fig", "pear"] │
│ "south" │ [2, 5, 8]   │ ["apple", "fig", "pear"] │
└─────────┴─────────────┴──────────────────────────┘

    A list column can be exploded back into rows, or asked questions with List().

    Every column at once¶

    GroupBy(...) has shortcuts that aggregate every column but the keys:

    • Sum(), Mean(), Median() and Quantile(q, interpolation) take the numeric columns;
    • Min(), Max(), First(), Last() and NUnique() take every column;
    • Count() counts each group's rows into a column named count, and Len(name) under a name of your own.
    df, err := sales().
    Select(ursus.Col("region"), ursus.Col("qty"), ursus.Col("price")).
    GroupBy(ursus.Col("region")).
    Max().
    Sort(ursus.Asc(ursus.Col("region"))).
    Collect(context.Background())
if err != nil {
    log.Fatal(err)
}
fmt.Println(df)
    Output
    shape: (3, 3)
┌─────────┬───────┬─────────┐
│ region  │ qty   │ price   │
│ String  │ Int64 │ Float64 │
├─────────┼───────┼─────────┤
│ "east"  │ 12    │ 2.25    │
│ "north" │ 10    │ 3       │
│ "south" │ 9     │ 3       │
└─────────┴───────┴─────────┘

    The whole frame¶

    An aggregate in Select is one value for the whole frame, so a Select of aggregates is one row. GroupBy() with no keys is the same, written as a group-by:

    df, err := sales().
    Select(
        ursus.Len().Alias("orders"),
        ursus.Col("qty").Sum().Alias("qty"),
        ursus.Col("qty").Mul(ursus.Col("price")).Sum().Alias("revenue"),
        ursus.Col("date").Max().Alias("last_day"),
    ).
    Collect(context.Background())
if err != nil {
    log.Fatal(err)
}
fmt.Println(df)
    Output
    shape: (1, 4)
┌────────┬────────┬─────────┬────────────┐
│ orders │ qty    │ revenue │ last_day   │
│ Uint64 │ Int128 │ Float64 │ Date       │
├────────┼────────┼─────────┼────────────┤
│ 8      │ 53     │ 108.75  │ 2026-01-07 │
└────────┴────────┴─────────┴────────────┘

    ValueCounts(exprs...) counts the rows of each distinct value, most frequent first, ties in the order their values first appear:

    df, err := sales().ValueCounts(ursus.Col("product")).Collect(context.Background())
if err != nil {
    log.Fatal(err)
}
fmt.Println(df)
    Output
    shape: (3, 2)
┌─────────┬────────┐
│ product │ count  │
│ String  │ Uint64 │
├─────────┼────────┤
│ "apple" │ 3      │
│ "pear"  │ 3      │
│ "fig"   │ 2      │
└─────────┴────────┘

    and Describe summarizes each column, as Polars' describe does:

    df, err := sales().
    Select(ursus.Col("qty"), ursus.Col("price")).
    Describe(context.Background())
if err != nil {
    log.Fatal(err)
}
fmt.Println(df)
    Output
    shape: (9, 3)
┌──────────────┬───────────────────┬────────────────────┐
│ statistic    │ qty               │ price              │
│ String       │ Float64           │ Float64            │
├──────────────┼───────────────────┼────────────────────┤
│ "count"      │ 8                 │ 8                  │
│ "null_count" │ 0                 │ 0                  │
│ "mean"       │ 6.625             │ 2.15625            │
│ "std"        │ 3.543101950067402 │ 0.6258922202972101 │
│ "min"        │ 2                 │ 1.5                │
│ "25%"        │ 4                 │ 1.5                │
│ "50%"        │ 7                 │ 2.25               │
│ "75%"        │ 9                 │ 2.25               │
│ "max"        │ 12                │ 3                  │
└──────────────┴───────────────────┴────────────────────┘

    Under a memory limit¶

    A group-by spills to disk when its groups outgrow the query's memory budget, a median's, a quantile's and an NUnique's values included, and gives the answer it gives in memory. Implode cannot divide its answer, and fails at the limit with an error that says so. See Memory and spilling.
